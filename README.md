# LASTING 

**LASTING** is a 2D survival game developed in Unity as a graduation project for Kodland.

## About the Game

Survive for **55 minutes and 30 seconds** while avoiding different obstacles. You have five lives, and every collision could bring you closer to Game Over.

Your objective is simple: **stay alive until the timer reaches zero.**

## Features

- **Four obstacle types:**
  - RedBurst
  - Rays
  - Mobile Squares
  - Expanding Circle
- **Five lives:** The player starts with five lives.
- **Dash mechanic:** Temporarily protects the player from obstacles.
- **Invulnerability system:** Prevents consecutive damage for a short period.
- **Survival timer:** Tracks the time survived.
- **Win condition:** Survive for 55 minutes and 30 seconds to win.
- **Game Over system:** The game ends when the player loses all five lives.
- **Background music:** Music plays during gameplay and stops when the game ends.

## Built With

- Unity 6
- C#
- TextMeshPro
- Unity 2D Physics
- Visual Studio 2022

## Objective

Survive for as long as possible, avoid the obstacles, manage your five lives, and reach the final goal.

**Can you LAST?**
